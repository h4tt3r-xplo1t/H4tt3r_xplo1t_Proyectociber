description: Inicia el trabajo sobre un issue de GitHub
---
Trabaja en el issue #$ARGUMENTS.
1. Lee el issue con `gh issue view $ARGUMENTS`.
2. Resume objetivo, alcance, exclusiones y criterios de aceptación.
3. Si falta algo crítico, haz UNA pregunta y detente.
4. Propón plan y nombre de rama. No edites hasta que apruebe.
